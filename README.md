# 🖼️ Image Gallery

A responsive image gallery built with HTML, CSS, and JavaScript as part of my CodeAlpha Frontend Development internship.

## 🚀 Live Demo
git remote add origin https://github.com/Muneeba-khalid/CodeAlpha_GalleryImage.git

## ✨ Features

- 📸 **Category Filtering** - Filter by Nature, City, Animals, Birds, Foods, Technology
- 🔍 **Lightbox View** - Click any image to view in fullscreen
- ⬅️➡️ **Navigation** - Next/Prev buttons in lightbox
- 🎨 **Hover Effects** - Smooth animations on image hover
- 📱 **Responsive Design** - Works on all devices
- ⌨️ **Keyboard Support** - Arrow keys navigation, Esc to close

## 🛠️ Technologies Used

- HTML5
- CSS3 (Grid, Flexbox, Animations)
- JavaScript (ES6)
